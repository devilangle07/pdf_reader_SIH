Act as a Principal Full-Stack Engineer and UX Architect. Build a modern, highly responsive, enterprise-grade Document Reader, Workbench & Universal File Converter Web Application using React/Next.js and WebAssembly.

### 1. Ultra-Large File Architecture (Up to 100 GB)
To process and convert massive files up to 100 GB without exhausting browser RAM:
- Local Memory Virtualization & Chunking: Use the File System Access API (showOpenFilePicker) and Blob.slice() to stream files off disk in byte chunks.
- WebAssembly (Wasm) Conversion & Parsing Engines: Offload binary file parsing, search indexing, and conversion (e.g., LibreOffice compiled to Wasm / Rust WebWorkers) to background threads.
- Virtualized Rendering (Windowing): Render only visible pages, cells, or paragraphs in the DOM using virtualized lists (e.g., react-window, TanStack Virtual).
- Stream-Based File Export: Write converted byte outputs directly to the native filesystem using FileSystemWritableFileStream.

### 2. File Conversion Engine Matrix
Implement a high-performance cross-format conversion pipeline:
- PDF Conversions:
  - PDF ➔ Word (.docx), Excel (.xlsx), Plain Text (.txt), Markdown (.md), Images (.png, .jpg), HTML.
  - OCR Conversion: Scanned PDF / Image ➔ Searchable PDF, Editable .docx, or .txt via Tesseract.js (Wasm).
- Office & eBook Conversions:
  - Word (.docx, .doc, .rtf, .odt) ➔ PDF, Markdown, Plain Text, HTML, EPUB.
  - Spreadsheets (.xlsx, .xls, .ods, .csv) ➔ PDF, CSV, JSON, HTML Table, Parquet.
  - Presentations (.pptx) ➔ PDF, Image Slides (.png), Outline Text.
  - EPUB / eBooks ➔ PDF, TXT, MOBI.
- Developer & Data Conversions:
  - Code / JSON / XML / YAML / Markdown ➔ PDF, HTML, Styled Text.
  - Large Datasets (Parquet / Arrow / Big-CSV) ➔ Filtered CSV, JSON, Excel (.xlsx).
- Batch Conversion Queue: Multi-file conversion job manager with progress indicators, stream pause/resume, and ZIP archive download support.

### 3. Expanded Document Format Support
Support viewing, searching, editing, and converting:
- PDF & Fixed Layouts: PDF (.pdf), XPS (.xps), EPUB (.epub), PostScript (.ps).
- Office Documents: Word (.docx, .doc, .rtf, .odt), Powerpoint (.pptx, .odp), Spreadsheets (.xlsx, .xls, .csv, .tsv, .ods).
